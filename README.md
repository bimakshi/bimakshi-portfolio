# Bimakshi Gunasekara - Personal Portfolio

A modern, professional personal portfolio website built with Next.js (App Router), TypeScript, Tailwind CSS, and Framer Motion.

## Features

- **Next.js App Router**: Modern and fast routing
- **Tailwind CSS**: Utility-first styling with a custom design system
- **Framer Motion**: Smooth scroll animations and page transitions
- **Dark Mode**: Built-in support for light and dark themes using `next-themes`
- **Fully Responsive**: Mobile-first design
- **SEO Optimized**: Open Graph tags and metadata included

## Setup Instructions

1. **Clone the repository** (if applicable) or navigate to the project folder.

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open your browser** and navigate to [http://localhost:3000](http://localhost:3000) to see the result.

## Data Management

All content (Projects, Skills, Education, Certifications) is managed centrally in `src/data/portfolio.ts`. You can easily update this file to reflect new experiences or skills without digging into the component code.
